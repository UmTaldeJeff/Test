COMO USAR NO SEU NZXT KRAKEN ELITE (100% OFICIAL & GRATUITO)

Por que isso não é pirataria? A própria NZXT criou um recurso oficial aberto chamado NZXT CAM Web Integration API. Tanto o site que você enviou quanto este estúdio usam essa API oficial documentada pela NZXT (`window.nzxt.v1`) para desenhar gráficos personalizados na bomba do watercooler.

Passo 1: Hospedar ou Rodar seu Estúdio

Salve este arquivo como index.html. Você pode subi-lo gratuitamente no GitHub Pages / Vercel / Netlify ou rodá-lo localmente no seu PC com 1 comando (VS Code Live Server ou Python python -m http.server 3000).

Passo 2: Colocar no NZXT CAM

  1. Abra o programa NZXT CAM e vá na aba Lighting (Iluminação).
  2. No modo do Display LCD, escolha Web Integration e clique em Custom Web Integration.
  3. Cole a URL do seu projeto com ?kraken=1 no final (exemplo: http://localhost:3000/?kraken=1).
  4. Quando o parâmetro ?kraken=1 está presente (ou quando o próprio Kraken carrega a página), toda a interface do editor desaparece automaticamente e apenas o círculo de 640x640 aparece no seu watercooler!

Passo 3: Editar Ao Vivo em Tempo Real!

Abra http://localhost:3000 no seu navegador normal (ou clique no botão Configure dentro do NZXT CAM). Tudo o que você arrastar, trocar de cor ou adicionar de GIF no Editor atualizará instantaneamente na tela do seu Kraken Elite em tempo real!
